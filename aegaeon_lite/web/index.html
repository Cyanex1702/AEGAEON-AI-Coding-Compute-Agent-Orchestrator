Choose how you want to work. You can reopen this guide from Getting started.

    

      
Try the offline demo
No model or account needed. Simulated model decisions make a fixed calculator repair; edits, tests and Git review are real.

      
Use a local model
Connect a model server you already run. Model manager can download selected official GGUF weights. A compatible runtime is still required. On an 8 GB PC, leave room for Windows and start with a small model and context.

      
Use a cloud notebook
Export a task, run the included notebook yourself, then bring back result.zip. Free GPU availability varies. Small Colab T4 workflows were tested; see release validation limits.

    

    
Check app prerequisites
This read-only check discovers Python and Git. It runs no project code and makes no model requests.
The report excludes source code, credentials, paths and machine names. Nothing is uploaded.
